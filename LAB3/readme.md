# DSA Lab 3 — Searching

A collection of C programs demonstrating **linear and binary searching techniques**.

### Topics

- Linear Search
- Binary Search
- Counting Occurrences
- Maximum Element Position
- First Occurrence
- Count in Sorted Array

### Exercises

1. Linear Search
2. Binary Search
3. Count Occurrences
4. Position of Maximum
5. First Occurrence via Binary Search
6. Count in Sorted Array

### Language
`C`
