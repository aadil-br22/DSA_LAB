# DSA Lab 2 — Arrays, Structures & Pointers

A collection of C programs demonstrating **arrays, structures, pointers, and functions**.

### Topics

- Pass by Value & Reference
- Arrays & Functions
- Pointer Arithmetic
- Structures & Functions
- Pointers to Structures
- Array of Structures

### Exercises

1. Swap — By Value vs By Reference
2. Array Sum & Maximum
3. Modify Array Using Function
4. Search Using Function
5. Structure — By Value vs By Pointer
6. Array of Structures — Find Topper

### Language
`C`
